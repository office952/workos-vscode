Referințe grafice (doar producție, nu UI mock):

- `litere-structura.svg` — structură / premontaj (structură metalică sau panou ACM casetat)

## Straturi per literă

| Strat | Producție | Note configurare |
|-------|-----------|------------------|
| **Vizual față** | Plexi/acrilic tăiat; opțional **colantare Oracal 651 sau 8500** | Colantare **la final**: după premontaj pe suport, sau înainte de montaj pe perete dacă nu există suport |
| **Volum aluminiu** | Profil aluminiu (laterale) | **Oracal 651 înainte de modelare** la mașină; **sau vopsire RAL doar după** lipire pe vizual față (cu șanfren/miter față) |
| **Bordură / lateral** | (alias volum aluminiu) | Adâncime return configurabilă |
| **Spate** | **Forex 10 mm** (nu PVC/aluminiu generic) | Șanfren spate: opțional/configurabil |
| **LED** | Module pe spate Forex; cablaj + sursă | Strat electric separat de față |
| **Finisaj** | Vopsire RAL / asamblare / QC / ambalare | — |

## Premontaj (opțional, separat de spatele literei)

- Montaj direct pe perete (dacă permite)
- Premontaj pe structură metalică
- Premontaj pe panou **Alucobond/ACM casetat** — **suport**, nu înlocuiește spatele Forex al literei

Cod operațional inventar pentru spate: `MAT-SPATE-PVC-LITERE` (denumire istorică; afișare: Forex 10 mm).
