# Pilot selection

Selected: **F6-LED**, **F6-ACM**, **F6-PROFILE** as operationally distinct isolated families.

Justification:
- different material units (buc / mp / ml)
- different task graphs (electrical vs CNC/v-groove vs form/bond)
- ACM declares machine applicability; others do not
- not renamed clones of 880041

Rejected as product proofs: 92401, 973019, catalog templates — real blockers, not invented substitutes.
