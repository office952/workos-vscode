| Code | Meaning |
|------|---------|
| `execution_closed_mutation_blocked` | Write rejected while closed |
| `execution_reopen_required` | Operator guidance companion |
| `execution_reopened` | Margin unavailable |
| `execution_not_closed` / `job_not_closed` | Final margin blocked |
| `material_movement_missing` | No consumption/scrap |
| `material_valuation_missing` / `material_valuation_unavailable` | Missing freeze |
| `material_return_unresolved` | Return without link |
| `machine_actual_not_captured` | Applicable but no usage fact |
| `machine_policy_missing` | No dated machine policy |
| `machine_not_applicable_by_job_profile` | Explicit N/A |
| `other_direct_not_declared` | Explicit N/A |
| `direct_cost_unclassified` | Reject unclassified bucket |
| `cost_category_required_incomplete` | Required category incomplete |
| `planned_bom_not_actual` / `reservation_not_actual` | Non-actual sources |
