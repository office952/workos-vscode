# Wave 4 top ten desktop gaps

Ordered by operator consequence, not ease of visual implementation.

1. **No singular Execution Closure truth.** A manager must infer closure readiness across plan/reality, post-job truth, stock, and profitability panels.
2. **Actual profitability is correctly unavailable but not decision-shaped.** Current evidence for order `973019` has actual minutes but no approved labor policy, material actual money, full task coverage, or actual margin.
3. **Execution Detail is overloaded.** It combines task control, observability, readiness, stock deduction, data quality, post-job truth, and two profitability panels.
4. **Legacy `ProfitabilityAnalysis` remains mounted.** It is labelled legacy, but its proximity to the newer read model risks contradictory interpretation.
5. **Parallel production homes remain.** Dashboard, Planificare, Shop Floor, Operator, Atelier, Ops-Graph, and Reality Review still compete for manager attention.
6. **Planned versus actual clarity stops before financial closure.** Minutes are explicit; actual monetary cost and margin need owner-policy and material-actual evidence.
7. **Pricing route reliability is unresolved.** The existing `Pricing.badges.test.tsx` maximum-update-depth failure prevents a stronger functional readiness claim.
8. **Visual debt persists beyond the shell.** Shop Floor/Operator and Product/Admin diagnostic panels retain slate/dark islands despite day-mode shell proof.
9. **Deep-route discoverability and coverage are weak.** Client workspace, employee profile, deepest tablet task, and many Product System details lack fresh operator-path proof.
10. **Runtime identity/console proof is stale.** Wave 3 blocked on incompatible API identity; U4A did not mutate a live stack, so all console-clean claims must remain qualified.

## What Wave 4 must not do

It must not make missing actuals appear as zero, convert minutes to money in the frontend, close jobs automatically, reprice an accepted order, alter inventory truth, or expose margin/salary data to operators. Those would hide the gaps rather than close them.
