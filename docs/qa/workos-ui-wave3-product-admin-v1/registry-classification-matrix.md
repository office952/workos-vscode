# Registry classification matrix

| Registry zone | Meaning | Not meaning |
|---|---|---|
| Materiale | Purchase-cost evidence and provenance | Inventory stock truth or a client price on its own |
| Reguli ofertă | Commercial markup/rules | Official offer snapshot |
| Cost intern estimativ | Labor/operation input toward internal cost evidence | Client tariff |
| Capacitate | Workcenter/utilaj feasibility and internal effort reference | Client pricing or offer activation |
| Legacy | Historical or not-yet-classified reference | New authority |

`rate_per_hour` is explicitly presented as **efort intern**, not a client tariff.
