# Desktop Information Hierarchy Reset

Functional truth stays frozen. Presentation levels redefine **what wins the eye**.

## Levels

| Level | Name | Operator need |
|-------|------|---------------|
| L1 | Must understand immediately | What product? What task now? |
| L2 | Must decide now | Primary physical / commercial decisions for active surface |
| L3 | System response | Calculated results, commercial estimate |
| L4 | Attention | Real blockers + actionable warnings only |
| L5 | Optional context | Success confirmations, informational notices |
| L6 | Technical | IDs, registries, hashes, Product System deep links, diagnostics |
