## Cross-cutting field-ledger observations

1. **Raw internal codes reach the operator UI in 3 separate places**: the shared warnings/info footer (`canonical_unresolved_warning:*`), the ACM "Detalii tehnice" JSON dump, and the ACM "Avansat" ownership paragraph. These are the same category of issue (internal vocabulary leaking past the localization boundary) but were introduced in at least 3 different components.
2. **Commercial adjustment widgets (Adaos/Discount/TVA/Ajustare manuală) are duplicated identically on every Configurare tab** rather than living in one persistent commercial panel — same 4 controls, same values, re-rendered 4 times.
3. **"Confirmare e o singură dată, la final" / one-way locks appear in 3 independent places** (ACM panel confirm, step-3 checkbox, layer role confirm) with no visible "undo/un-confirm" affordance in any of them within this session — consistent pattern, but also consistently missing a reverse path, which the ledger's "reverse behavior" column had to mark "not tested / not found" almost everywhere.
4. **The `—` (unset) option sits inside otherwise-numeric select lists** (e.g. Adâncime cant) rather than being visually distinct from real values.
