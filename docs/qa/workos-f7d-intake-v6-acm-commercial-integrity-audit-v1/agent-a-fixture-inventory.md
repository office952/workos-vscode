## Summary

- **1 fixture tested live** end-to-end this session: `test-bond-litere.svg` (the mission's primary target).
- **2 direct siblings of the primary fixture** (`doar-panou.svg`, `doar litere.svg`) exist in the same folder and were **not** exercised — they would isolate the ACM-only and letters-only paths respectively and are low-effort follow-ups (same folder, same upload mechanism already proven working).
- **`pbl-complex.svg`** is the single highest-value untested fixture in the repo for a deeper ACM audit — it is the only one combining an ACM background with **two** letter groups, a logo, and cutout text in one file, which would exercise composition/duplication logic this audit could not reach with the single-letter-group primary fixture.
- **`annes-store-volumetric.svg`** is worth a manual pass because it uses explicit `data-role` attributes instead of relying on the AI-inferred layer-name matching that `test-bond-litere.svg` went through — comparing the two would show whether explicit vs. inferred role assignment produces identical ACM panel behavior.
- **Two filenames are misleading** (`litere-cu-fundal-acm-segmentat*.svg`, `LITERE-VOLUMETRICE-ACP.svg`) — they reference ACM/ACP in the name but contain no actual support-panel layer. This is a minor repo-hygiene finding, not a product bug, but could cost a future agent time if picked based on filename alone without opening the file first.
